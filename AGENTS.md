# tutorials

This repository is a catalog of links. It does not contain tutorial source.

Do not read, copy, or submodule the sibling tutorial repositories unless the user names that tutorial.

To add a tutorial, append one object to `catalog.json`:

```json
{
  "title": "Name",
  "description": "One line.",
  "url": "https://tiwari1302.github.io/repo-name/"
}
```

`index.html` only renders `catalog.json`. Do not paste tutorial content into this repo.
